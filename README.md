# Code-Snippet-Hub

👧 自用脚本与配置库：Apifox 前置自动设置 authorization、右键菜单注册（.reg）等日常效率小件。

[English](README.en.md)

## 内容

| 文件 | 用途 |
| --- | --- |
| `apifox前置自动设置authorization` | Apifox 请求前自动注入 authorization 头 |
| `iflow_context_menu.reg` | 注册应用右键打开菜单 |
| `清除右键菜单配置.reg` | 清理上述右键菜单项 |

## 说明

脚本以个人环境为准，运行 `.reg` 前建议先备份注册表。
